## Calendar — Source of Truth

**Open this first for any posting work:** the active month's `<MONTH>-CALENDAR.md` at project root.

The calendar is **the single source of truth** for what gets posted when. Writers do NOT improvise around it — if the calendar says "WRITE: cold-traffic angle on [topic]," the cold-traffic angle is the assignment, not a suggestion.

**Mandatory before drafting any post (status WRITE):**

1. Read the day's row in the daily-posts table — the angle is specified there. Do not pull a quote and default back to a warm/identity-led shape unless the row explicitly calls for that.
2. Run the **5-question Conversion Checklist** (in the strategy file's Amplifiers section, if present) on every draft before handoff:
   - Opens with the problem, not context?
   - Exactly ONE CTA?
   - Hook survives a 0.5-second scroll test?
   - Has a pattern-interrupt line?
   - Visual matches the angle?
3. If any answer is "no" → rewrite that element. Do not ship until all five are "yes."
